# Alicore brand guidelines

ALICORE manufactures architectural products (GFRC and FRP) for architects,
builders, developers, contractors, and designers. Every page should read like an
established international architectural-products manufacturer — not a small local
construction company.

## Must communicate

Premium quality, architectural excellence, engineering capability, custom
manufacturing, reliability, large-project capability, modern manufacturing,
professionalism, innovation.

## Visual direction

- Palette: charcoal/near-black, warm white, light concrete grey, a subtle
  metallic/gold accent. (Confirm exact hex values from the mockup's `<style>` block
  via the dc-mockup-parsing skill — this is the intent, not the literal codes.)
- Generous white space; modern premium sans-serif with strong bold headings and
  clean readable body text.
- Large architectural photography: facades, GFRC/FRP textures, jalis, panels,
  manufacturing/process shots. Minimal animation, smooth scrolling, premium
  transitions.
- Avoid: cheap stock-photo look, excessive gradients, cartoon graphics, too many
  colors, crowded layouts, generic construction-company templates.

## Claims — hard rules

Never state or imply, unless a real, verified source is supplied for it:
- "Number one," "largest manufacturer," "world's best," "guaranteed," "100%
  maintenance free"
- ISO certification or any specific testing/international standard
- Invented project names, clients, or locations in the Projects section — use
  "Project Name — Coming Soon" (or similarly named placeholders) until real project
  data is provided

Tone for the About page and elsewhere: confident but not exaggerated.

## Site structure (per the brief)

Nine topics the site must cover: Home, About Alicore, Products, GFRC, FRP, Projects,
Custom Solutions, Manufacturing, Contact. (Whether each becomes its own routed page
or an anchored section of a longer page is a decision for the site-planner agent —
see the root CLAUDE.md.)

Core CTAs used throughout: "Request a Quote," "Talk to Our Team," "View Products,"
"Discuss Your Project." Strong enquiry/quotation buttons should appear throughout
the site, not just on the Contact page.

## SEO keywords (use naturally, do not stuff)

GFRC manufacturer, GFRC architectural products, GFRC panels, GFRC jali, GFRC
cornice, GFRC facade panels, FRP architectural products, FRP manufacturer,
architectural products manufacturer, architectural facade solutions, custom GFRC
products, custom FRP products.

## Priority order when trading off decisions

1. Professional appearance
2. Product presentation
3. Trust
4. Project capability
5. Easy quotation enquiries
6. Mobile responsiveness
7. Fast loading
8. SEO
9. Clear contact options
